# IPL Data Analysis

## About the Project

This project analyzes IPL match data using Python to explore team performance, match results, toss decisions, player performance, and season-wise trends.

The analysis uses historical IPL match data to identify patterns in team wins, toss decisions, player of the match awards, and season performance.

## Tech Stack Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Analysis

- Analyzed 1,095 IPL matches.
- Analyzed team-wise match results.
- Analyzed toss decisions and their relationship with match results.
- Analyzed player of the match awards.
- Analyzed season-wise match performance.
- Compared team performance across matches and seasons.
- Created visualizations to identify trends and patterns.

## Work Done

- Loaded and explored IPL match data using Pandas.
- Cleaned and prepared the dataset for analysis.
- Performed exploratory data analysis.
- Used Pandas and NumPy for data manipulation.
- Created charts and visualizations using Matplotlib and Seaborn.
- Analyzed team, toss, player, and season-level patterns.
